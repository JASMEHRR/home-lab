# PS2 Home Lab

Old PlayStation 2 accessories brought back to life on a Windows laptop, plus a small Fire TV app.

| Folder or file | What it does |
|---|---|
| `eyetoy.py`, `EyeToy Camera.bat` | Uses the PS2 EyeToy as a webcam |
| `buzz.py`, `Fix Buzz.bat`, `Test Buzz.bat` | Gets the Buzz! quiz buzzers working as controllers, including a driver fix |
| `posture/` | A posture coach: watches how I sit through the camera, warns me, and writes a daily report |
| `send-to-tv/` | **Send to TV**, a Fire TV app: shows a QR code, and a page on the phone then talks to the TV. Includes an ad-block list |

The `.bat` and `.lnk` files are one-click launchers. Personal posture data and signing keys stay on the laptop and are not in this repo.
